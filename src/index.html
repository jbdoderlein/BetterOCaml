Shortcuts

    
Editor

    

        
 + Enter
Run the highlighted phrase

        
 + Shift + Enter
Run all the code

        
 + Space
Show completions

        
F12,  + click
Go to definition

        
Alt + T
Type and documentation at the cursor

        
F8
Next error

        
 + Shift + M
List of errors

        
 + S
Save the file

        
 + /
Comment or uncomment

        
 + Z,  + Shift + Z
Undo, redo

    

    
Search

    

        
 + F
Search and replace

        
F3,  + G
Next match

        
Shift + F3,  + Shift + G
Previous match

        
 + D
Select the next occurrence

        
Alt + G
Go to line

    

    
Toplevel

    

        
Enter
Run the input

        
Shift + Enter
New line

        
↑ ↓
History

        
 + K
Clear the toplevel

        
 + L
Reset the OCaml interpreter

    

    
Keyboard navigation

    

        
Esc then Tab
Leave the editor or the toplevel input (Tab alone indents)

        
Ctrl + M (macOS: Alt + Shift + M)
In the editor: Tab moves the focus, until pressed again

        
← →, Home, End
In the file tabs: change file

        
Delete
In the file tabs: close the file
